Benchmark transfer overlap¶

Benchmark overlap between D2H transfers and foreground CUDA compute.

The intended use of spdl.io.transfer_tensor_d2h() is to call it from a background CPU thread while the foreground thread submits independent CUDA work. Raw transfer latency alone does not measure that benefit, so this benchmark compares serialized and concurrent transfer-plus-compute makespans. The PyTorch to(cpu) method is a simple reference path, not a staging- and allocation-matched replacement for SPDL.

The source tensors are made ready before timing. The transfer worker owns its copy stream, while the foreground thread owns a separate compute stream. Each timed block runs compute-only, transfer-only, serialized, and concurrent cases in randomized order. Concurrent cases use a CPU barrier and report CPU launch skew so delayed worker scheduling is visible in the result.

Usage:

python examples/benchmark_transfer_overlap.py         --output /tmp/transfer_overlap.csv

Use --samples-output to retain paired per-trial measurements.

Measured steady-state result¶

One run used a 64 MiB uint8 payload on an NVIDIA A100 MIG 1g.10gb with CUDA 13.3. After five warmup blocks, 30 paired randomized blocks produced the following SPDL medians. The foreground workload was a 2048-square torch.mm.

Tensors  Compute   Transfer  Serialized  Concurrent  Paired speedup (95% CI)
      1  7.262 ms  9.800 ms   17.012 ms    11.852 ms  1.471x [1.266, 1.670]
     32  7.310 ms 11.443 ms   17.757 ms    11.626 ms  1.625x [1.428, 1.693]

These are steady-state results: validation and warmup prime the pinned-memory and allocator caches before timing. They show that background SPDL execution reduced transfer-plus-compute makespan on this system. They do not show that SPDL is faster than the naive PyTorch reference, which also overlaps, or characterize first-call and cache-growth latency.

 86@dataclass(frozen=True)
 87class OverlapSample:
 88    """Paired measurements from one randomized benchmark block."""
 89
 90    trial: int
 91    schedule_order: str
 92    compute_only_ms: float
 93    transfer_only_ms: float
 94    serialized_ms: float
 95    concurrent_ms: float
 96    cpu_launch_skew_ms: float
 97
 98    @property
 99    def speedup(self) -> float:
100        """Return serialized-to-concurrent makespan speedup."""
101        return self.serialized_ms / self.concurrent_ms
102
103    @property
104    def hidden_ms(self) -> float:
105        """Return time saved by concurrent execution."""
106        return self.serialized_ms - self.concurrent_ms
107
108    @property
109    def estimated_overlap_efficiency(self) -> float:
110        """Estimate saved time as a fraction of the paired overlap potential.
111
112        The four schedules are timed separately, so noise can produce estimates
113        outside the interval from zero to one.
114        """
115        potential_ms = min(self.compute_only_ms, self.transfer_only_ms)
116        return self.hidden_ms / potential_ms if potential_ms > 0 else 0.0

198def _native_d2h(
199    tensors: list[torch.Tensor], stream: torch.cuda.Stream
200) -> list[torch.Tensor]:
201    """Transfer tensors to pageable CPU outputs on a dedicated stream."""
202    producer_stream = torch.cuda.current_stream(tensors[0].device)
203    if producer_stream != stream:
204        stream.wait_stream(producer_stream)
205    with torch.cuda.stream(stream):
206        output = [tensor.to("cpu", non_blocking=True) for tensor in tensors]
207    stream.synchronize()
208    return output

211def _submit_transfer(
212    executor: ThreadPoolExecutor,
213    fn: Callable[[], list[torch.Tensor]],
214    device: torch.device,
215    barrier: threading.Barrier | None = None,
216) -> Future[_TransferOutcome]:
217    """Submit one transfer to the persistent background worker."""
218
219    def _work() -> _TransferOutcome:
220        torch.cuda.set_device(device)
221        if barrier is not None:
222            barrier.wait(timeout=30)
223        started_ns = time.perf_counter_ns()
224        output = fn()
225        return _TransferOutcome(output, started_ns)
226
227    return executor.submit(_work)

230def _elapsed_ms(start_ns: int, end_ns: int) -> float:
231    """Convert a monotonic nanosecond interval to milliseconds."""
232    return (end_ns - start_ns) / 1_000_000

235def _time_compute(run_compute: Callable[[], torch.Tensor]) -> float:
236    """Measure one synchronous foreground-compute call."""
237    start_ns = time.perf_counter_ns()
238    run_compute()
239    return _elapsed_ms(start_ns, time.perf_counter_ns())

242def _time_transfer(
243    executor: ThreadPoolExecutor,
244    fn: Callable[[], list[torch.Tensor]],
245    device: torch.device,
246) -> float:
247    """Measure one end-to-end background transfer."""
248    start_ns = time.perf_counter_ns()
249    outcome = _submit_transfer(executor, fn, device).result()
250    end_ns = time.perf_counter_ns()
251    del outcome
252    return _elapsed_ms(start_ns, end_ns)

255def _time_serialized(
256    executor: ThreadPoolExecutor,
257    fn: Callable[[], list[torch.Tensor]],
258    run_compute: Callable[[], torch.Tensor],
259    device: torch.device,
260) -> float:
261    """Measure transfer followed by foreground compute."""
262    start_ns = time.perf_counter_ns()
263    outcome = _submit_transfer(executor, fn, device).result()
264    run_compute()
265    end_ns = time.perf_counter_ns()
266    del outcome
267    return _elapsed_ms(start_ns, end_ns)
268
269
270def _time_concurrent(
271    executor: ThreadPoolExecutor,
272    fn: Callable[[], list[torch.Tensor]],
273    run_compute: Callable[[], torch.Tensor],
274    device: torch.device,
275) -> tuple[float, float]:
276    """Measure barrier-coordinated transfer and foreground compute."""
277    barrier = threading.Barrier(2)
278    start_ns = time.perf_counter_ns()
279    future = _submit_transfer(executor, fn, device, barrier)
280    barrier.wait(timeout=30)
281    compute_started_ns = time.perf_counter_ns()
282    run_compute()
283    outcome = future.result()
284    end_ns = time.perf_counter_ns()
285    launch_skew_ms = _elapsed_ms(
286        min(compute_started_ns, outcome.started_ns),
287        max(compute_started_ns, outcome.started_ns),
288    )
289    del outcome
290    return _elapsed_ms(start_ns, end_ns), launch_skew_ms

298def _bootstrap_median_ci(
299    values: Sequence[float], *, seed: int, num_resamples: int
300) -> tuple[float, float]:
301    """Return a percentile-bootstrap 95% confidence interval for the median."""
302    samples = np.asarray(values, dtype=np.float64)
303    rng = np.random.default_rng(seed)
304    indices = rng.integers(0, len(samples), size=(num_resamples, len(samples)))
305    medians = np.median(samples[indices], axis=1)
306    return (
307        float(np.percentile(medians, 2.5)),
308        float(np.percentile(medians, 97.5)),
309    )

312def _calibrate_compute_iterations(
313    run_compute: Callable[[int], torch.Tensor], target_ms: float
314) -> int:
315    """Calibrate real matrix multiplication to an independent duration target."""
316    iterations = 1
317    for _ in range(4):
318        samples = []
319        for _ in range(3):
320            start_ns = time.perf_counter_ns()
321            run_compute(iterations)
322            samples.append(_elapsed_ms(start_ns, time.perf_counter_ns()))
323        measured_ms = _percentile(samples, 50)
324        estimate = round(iterations * target_ms / max(measured_ms, 0.001))
325        estimate = max(1, min(100_000, estimate))
326        if estimate == iterations:
327            break
328        iterations = estimate
329    return iterations

332def _create_source_tensors(
333    total_bytes: int, num_tensors: int, device: torch.device
334) -> list[torch.Tensor]:
335    """Create uint8 CUDA tensors whose sizes sum to ``total_bytes``."""
336    if num_tensors > total_bytes:
337        raise ValueError(
338            f"Cannot split {total_bytes} bytes into {num_tensors} nonempty tensors."
339        )
340    size, remainder = divmod(total_bytes, num_tensors)
341    return [
342        torch.randint(
343            0,
344            256,
345            (size + (index < remainder),),
346            dtype=torch.uint8,
347            device=device,
348        )
349        for index in range(num_tensors)
350    ]

353def _validate_methods(
354    executor: ThreadPoolExecutor,
355    methods: dict[str, Callable[[], list[torch.Tensor]]],
356    tensors: list[torch.Tensor],
357    device: torch.device,
358) -> None:
359    """Prime each method on the worker and validate exact transfer results."""
360    expected = [tensor.cpu() for tensor in tensors]
361    for method in methods.values():
362        outcome = _submit_transfer(executor, method, device).result()
363        for actual, reference in zip(outcome.output, expected, strict=True):
364            torch.testing.assert_close(actual, reference)
365        del outcome

368def _collect_samples(
369    executor: ThreadPoolExecutor,
370    methods: dict[str, Callable[[], list[torch.Tensor]]],
371    run_compute: Callable[[], torch.Tensor],
372    device: torch.device,
373    *,
374    num_warmup: int,
375    num_runs: int,
376    seed: int,
377) -> dict[str, list[OverlapSample]]:
378    """Collect randomized, paired timing blocks for every transfer method."""
379    for _ in range(num_warmup):
380        run_compute()
381        for method in methods.values():
382            _time_transfer(executor, method, device)
383            _time_concurrent(executor, method, run_compute, device)
384
385    rng = random.Random(seed)
386    samples = {method: [] for method in methods}
387    cases = [("compute", "")]
388    cases.extend(
389        (method, schedule)
390        for method in methods
391        for schedule in ("transfer", "serialized", "concurrent")
392    )
393
394    for trial in range(num_runs):
395        order = list(cases)
396        rng.shuffle(order)
397        order_label = "|".join(
398            method if method == "compute" else f"{method}:{schedule}"
399            for method, schedule in order
400        )
401        compute_only_ms = 0.0
402        trial_results = {method: _MutableTrial() for method in methods}
403        for method, schedule in order:
404            if method == "compute":
405                compute_only_ms = _time_compute(run_compute)
406                continue
407
408            transfer = methods[method]
409            result = trial_results[method]
410            if schedule == "transfer":
411                result.transfer_only_ms = _time_transfer(executor, transfer, device)
412            elif schedule == "serialized":
413                result.serialized_ms = _time_serialized(
414                    executor, transfer, run_compute, device
415                )
416            else:
417                (
418                    result.concurrent_ms,
419                    result.cpu_launch_skew_ms,
420                ) = _time_concurrent(executor, transfer, run_compute, device)
421
422        for method, result in trial_results.items():
423            samples[method].append(
424                OverlapSample(
425                    trial=trial,
426                    schedule_order=order_label,
427                    compute_only_ms=compute_only_ms,
428                    transfer_only_ms=result.transfer_only_ms,
429                    serialized_ms=result.serialized_ms,
430                    concurrent_ms=result.concurrent_ms,
431                    cpu_launch_skew_ms=result.cpu_launch_skew_ms,
432                )
433            )
434    return samples

536def _run_benchmarks(
537    config: BenchmarkConfig, device: torch.device
538) -> tuple[list[BenchmarkSummary], list[RawSampleRecord]]:
539    """Run all configured overlap scenarios and return summary and raw rows."""
540    torch.manual_seed(config.seed)
541    torch.cuda.set_device(device)
542    current_index = torch.cuda.current_device()
543    device = torch.device("cuda", current_index)
544
545    left = torch.randn(config.matrix_size, config.matrix_size, device=device)
546    right = torch.randn(config.matrix_size, config.matrix_size, device=device)
547    compute_output = torch.empty_like(left)
548    compute_stream = torch.cuda.Stream(device=device)
549    compute_stream.wait_stream(torch.cuda.current_stream(device))
550
551    def _run_compute(iterations: int) -> torch.Tensor:
552        with torch.cuda.stream(compute_stream):
553            for _ in range(iterations):
554                torch.mm(left, right, out=compute_output)
555        compute_stream.synchronize()
556        return compute_output
557
558    _run_compute(1)
559    compute_iterations = config.compute_iterations
560    if compute_iterations is None:
561        compute_iterations = _calibrate_compute_iterations(
562            _run_compute, config.compute_target_ms
563        )
564
565    def _compute() -> torch.Tensor:
566        return _run_compute(compute_iterations)
567
568    _compute()
569    if not torch.isfinite(compute_output).all().item():
570        raise RuntimeError(
571            "Foreground matrix multiplication produced non-finite output."
572        )
573
574    created_utc = datetime.now(timezone.utc).isoformat()
575    summaries = []
576    raw_records = []
577    scenarios = [
578        (total_mib * 1024 * 1024, num_tensors)
579        for total_mib in config.total_mib
580        for num_tensors in config.num_tensors
581    ]
582    random.Random(config.seed).shuffle(scenarios)
583
584    with ThreadPoolExecutor(
585        max_workers=1, thread_name_prefix="spdl-d2h-benchmark"
586    ) as executor:
587        for scenario_index, (total_bytes, num_tensors) in enumerate(scenarios):
588            print(
589                f"\n{total_bytes / (1024 * 1024):.0f} MiB in "
590                f"{num_tensors} tensor(s), {compute_iterations} compute iteration(s)"
591            )
592            tensors = _create_source_tensors(total_bytes, num_tensors, device)
593            torch.cuda.synchronize(device)
594            native_stream = torch.cuda.Stream(device=device)
595            methods: dict[str, Callable[[], list[torch.Tensor]]] = {
596                _METHOD_NATIVE: partial(_native_d2h, tensors, native_stream),
597                _METHOD_SPDL: partial(transfer_tensor_d2h, tensors, device=device),
598            }
599            _validate_methods(executor, methods, tensors, device)
600            scenario_seed = config.seed + scenario_index * 1009
601            samples = _collect_samples(
602                executor,
603                methods,
604                _compute,
605                device,
606                num_warmup=config.num_warmup,
607                num_runs=config.num_runs,
608                seed=scenario_seed,
609            )
610            for method_index, (method, method_samples) in enumerate(samples.items()):
611                bootstrap_seed = scenario_seed + method_index * 17
612                summary = _summarize(
613                    method_samples,
614                    created_utc=created_utc,
615                    device=device,
616                    config=config,
617                    total_bytes=total_bytes,
618                    num_tensors=num_tensors,
619                    compute_iterations=compute_iterations,
620                    method=method,
621                    schedule_seed=scenario_seed,
622                    bootstrap_seed=bootstrap_seed,
623                )
624                summaries.append(summary)
625                _print_summary(summary)
626                raw_records.extend(
627                    RawSampleRecord(
628                        schema_version=_SCHEMA_VERSION,
629                        created_utc=created_utc,
630                        seed=config.seed,
631                        schedule_seed=scenario_seed,
632                        total_bytes=total_bytes,
633                        num_tensors=num_tensors,
634                        method=method,
635                        trial=sample.trial,
636                        schedule_order=sample.schedule_order,
637                        compute_only_ms=sample.compute_only_ms,
638                        transfer_only_ms=sample.transfer_only_ms,
639                        serialized_ms=sample.serialized_ms,
640                        concurrent_ms=sample.concurrent_ms,
641                        speedup=sample.speedup,
642                        hidden_ms=sample.hidden_ms,
643                        estimated_overlap_efficiency=(
644                            sample.estimated_overlap_efficiency
645                        ),
646                        cpu_launch_skew_ms=sample.cpu_launch_skew_ms,
647                    )
648                    for sample in method_samples
649                )
650            del tensors
651
652    return summaries, raw_records

transfer_tensor_d2h(batch: T, /, *, device: TDevice | str | None = None, stream: torch.cuda.Stream | None = None) → T[source]¶

Transfer PyTorch CUDA tensors to CPU through a dedicated stream.

Added in version 0.7.0.

This function performs efficient GPU to CPU data transfer using page-locked (pinned) memory and a dedicated CUDA stream. The page-locked memory is cached and reused across calls.

The transfer process: 1. Gathers all tensors from the batch. 2. Allocates (or reuses cached) page-locked memory. 3. Asynchronously transfers data from GPU to page-locked memory. 4. Copies data from page-locked memory to new CPU tensors. 5. Rebuilds the batch structure with CPU tensors.

The copy stream waits for work already submitted to the caller’s current stream, and this function waits for the copy stream before returning. If a tensor was produced on another non-current stream, the caller must first establish an ordering dependency with the current stream. When called from a background CPU thread, the transfer can overlap with later GPU work submitted independently by a foreground thread. It is intended for offloading nested results before CPU post-processing or serialization.

If any transferred tensor requires gradients, the function uses a synchronous per-tensor transfer on the caller’s current stream to preserve autograd.

Example

import torch
from spdl.io import transfer_tensor_d2h

batch = {"scores": torch.randn(32, device="cuda:0")}
cpu_batch = transfer_tensor_d2h(batch, device="cuda:0")
Parameters:

  • batch – A torch.Tensor or a composition of tensors with container types such as list, tuple, dict and dataclass.

  • device –

    Optional CUDA device to transfer data from.

    If None the source device is determined by the LOCAL_RANK environment variable. If not set, cuda:0 is used.

  • stream –

    Optional Custom CUDA stream to use for the transfer. If None, a stream is created from the device argument, and cached to a thread-local storage for future reuse.

    When stream is not None, the device argument must be provided. The stream must be on the same device.

Returns:

An object of the same type as the input, but the PyTorch CUDA tensors on the specified device are transferred to CPU.

If there is no PyTorch tensor in the input, the input is returned as-is.

If there is no CUDA device available, the input is returned as-is.

Raises:

  • ValueError – If device is not a CUDA device, or a custom stream does not match the requested device.

  • RuntimeError – If the resolved CUDA device index is unavailable.

[sep] -> string in ISO 8601 format, YYYY-MM-DDT[HH[:MM[:SS[.mmm[uuu]]]]][+HH:MM]. sep is used to separate the year from the time, and defaults to ‘T’. The optional argument timespec specifies the number of additional terms of the time to include. Valid options are ‘auto’, ‘hours’, ‘minutes’, ‘seconds’, ‘milliseconds’ and ‘microseconds’.
